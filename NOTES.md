## Pick

Candidate 16 wins on persuasion + warmth: it tells the friend they already own
the hard part, names the mechanism (agent handles the coding) and the payoff
(a working app back). Its only weak point is "free", which I cannot verify as
true of the build itself — the competition is free to enter, but the pitch's
claim would be read as the build costing nothing.

## Polish round (1)

Change: drop the unverified "free" and name the zero-code payoff explicitly
instead, and make the mechanism active ("describe it in plain words") rather
than passive ("let an agent handle it").

Before (139 chars):
"You already have the hard part — the idea — so let an AI agent on make.fun handle the coding and hand you back a working app, free."

After (157 chars):
"You already have the hard part — the idea — so describe it in plain words to an AI agent on make.fun and it'll hand you back a working app, no coding needed."

Why better: every claim is now verifiable (describe in plain words -> agent
builds -> working app back; no coding needed by the friend), the friend is the
actor, and the sentence keeps the "hard part" hook that scored highest on
warmth and persuasion. One sentence, 157 characters, well under the 240 gate.
